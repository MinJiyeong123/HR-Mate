# 2차 요구사항: 월별 급여 관리 (포트폴리오용 시뮬레이션)

> **고지**
> - 급여 금액은 사용자가 직접 입력하고, 시스템은 합계와 실지급액(지급 합계 − 공제 합계)만 계산합니다.
> - 소득세, 지방소득세, 4대보험료는 **자동 산출하지 않습니다.** 공제 항목으로 금액만 수동 입력합니다.
> - 모든 급여 화면과 명세서에 "포트폴리오용 시뮬레이션이며 실제 급여·세금 산출 결과가 아님"을 표시합니다.
> - 세법·보험료 자동 산출은 과세연도별 공식 기준을 확인·검증하는 별도 단계 전까지 구현하지 않습니다.

## 1. 범위

**포함**
- 급여 기간(귀속 연월) 생성, 지급일 수정, 확정, 확정 취소
- 사원별 월 급여 입력·수정·삭제(작성 중일 때만), 급여명세서 확인·인쇄
- 지급·공제 항목별 금액 입력, 합계·실지급액 계산

**제외 (추후 단계)**
- 세금·보험료 자동 계산, 비과세 한도 검사
- 연말정산 (연간 급여 집계는 3차에서 추가, 6장)
- 항목 관리 화면(항목 추가·수정), 확정·취소 이력, 은행 이체, 엑셀 내보내기

## 2. 금액

- 원 단위 정수(DB `BIGINT`, Java `long`). 소수점 없음.
- 항목 금액: 1원 이상 1,000,000,000원 이하. 0원이거나 비어 있는 항목은 저장하지 않습니다.

## 3. 급여 항목 (기본 12개, V2 마이그레이션으로 등록)

| 구분 | 항목 (코드) | 과세 구분 |
|---|---|---|
| 지급 | 기본급 (BASE_SALARY) | 과세 |
| 지급 | 연장근로수당 (OVERTIME_PAY) | 과세 |
| 지급 | 상여금 (BONUS) | 과세 |
| 지급 | 식대 (MEAL_ALLOWANCE) | 비과세 |
| 지급 | 기타수당 (OTHER_ALLOWANCE) | 과세 |
| 공제 | 소득세 (INCOME_TAX) | - |
| 공제 | 지방소득세 (LOCAL_INCOME_TAX) | - |
| 공제 | 국민연금 (NATIONAL_PENSION) | - |
| 공제 | 건강보험 (HEALTH_INSURANCE) | - |
| 공제 | 장기요양보험 (LONG_TERM_CARE) | - |
| 공제 | 고용보험 (EMPLOYMENT_INSURANCE) | - |
| 공제 | 기타공제 (OTHER_DEDUCTION) | - |

- 공제 항목은 모두 수동 입력입니다.
- "비과세"는 분류 표시만 합니다. 법령상 한도·요건은 검사하지 않으며, 연간 집계 전에 과세연도별 공식 기준으로 확인합니다.

## 4. 급여 기간

- 귀속 연월당 1개. 연도 2000~2100, 월 1~12.
- 지급일 필수. 귀속 연월과 지급일을 모두 저장합니다. 연간 집계 기준은 3차에서 귀속 연도로 결정했습니다(아래 6장).
- 상태: 작성 중(DRAFT) → 확정(CONFIRMED). 급여가 1건 이상일 때만 확정할 수 있습니다.
- 확정 취소 허용(확인창을 거침). 확정·취소 이력은 기록하지 않습니다.
- 확정된 기간은 지급일 수정, 급여 입력·수정·삭제가 모두 불가합니다.

## 5. 사원별 월 급여

- 한 기간에 사원당 1건.
- 대상 사원: 논리 삭제되지 않았고, 해당 월에 재직한 사원
  (입사일 ≤ 해당 월 말일, 퇴사일이 없거나 퇴사일 ≥ 해당 월 1일)
- 작성 당시 사번·이름·부서·직급을 복사해서 저장합니다(스냅샷). 이후 사원 정보가 바뀌어도 명세서는 당시 기준을 유지합니다.
- 지급 항목이 1개 이상(금액 > 0) 있어야 합니다. 같은 항목은 한 번만 입력합니다.
- 합계는 서버가 항목 금액으로 다시 계산합니다. 공제 합계가 지급 합계보다 크면 저장을 거부합니다(실지급액 ≥ 0).
- 메모 200자 이하.
- 작성 중인 급여는 삭제할 수 있고(실제 삭제), 확정된 급여는 삭제할 수 없습니다.
- 급여 기록이 있는 사원도 사원 삭제는 논리 삭제이므로 급여 기록은 그대로 남습니다.

## 6. 연간 급여 집계 (3차)

- 기준: **귀속 연도(`pay_year`)**. 귀속 월을 근로를 제공한 달로 간주합니다. 근거와 확인하지 못한 항목은 [tax-rules/income-attribution.md](tax-rules/income-attribution.md) (전문가 검증 전).
- **확정된 기간의 급여만** 합산하고, 제외된 작성 중 기간(사원별 상세는 작성 중 급여) 수를 함께 보여줍니다.
- 지급·과세 지급·비과세 지급·공제·실지급 합계. 과세 구분은 급여 입력 당시 복사해 둔 값이며 비과세 한도는 검사하지 않습니다.
- 논리 삭제된 사원도 포함하고 삭제됨으로 표시합니다. 사원 정보는 그 해 마지막 확정 급여의 스냅샷입니다.
- 조회할 때마다 계산합니다(별도 테이블·마이그레이션 없음).
- 포트폴리오용 시뮬레이션이며 공식 원천징수·연말정산 자료가 아닙니다.
