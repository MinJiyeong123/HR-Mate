# 4차 요구사항: 연말정산 모의 계산 (포트폴리오용 시뮬레이션)

> **고지**
> - 이 기능의 결과는 **모의 계산**이며 공식 연말정산 결과가 아닙니다. 세무 전문가의 검증을 받지 않았습니다.
> - 계산 규칙은 **2025년 귀속** 기준입니다. 원문과 해석: [tax-rules/year-end-settlement-2025.md](tax-rules/year-end-settlement-2025.md)
> - 급여 금액은 사용자가 직접 입력한 시뮬레이션 값이므로, 계산 결과도 그 값에 따라 달라집니다.
> - 모든 연말정산 화면에 "모의 계산 · 전문가 검증 전 · 지방소득세 미포함"을 표시합니다.

## 1. 범위

**포함**
- 사원·귀속연도별 연말정산 입력 자료(인원 수·해당 여부) 저장, 수정
- 계산: 총급여 → 근로소득공제 → 인적공제 → 연금보험료공제·보험료 특별소득공제 → 과세표준 → 산출세액 → 근로소득·자녀·표준세액공제 → 결정세액 → 기납부세액과 비교(추가 납부 / 환급)
- 계산 단계별 금액과 적용 규칙 표시, 경고 문구

**제외 (추후 후보)**
- 신용카드 등 소득공제, 주택자금 공제, 소득공제 종합한도
- 보장성보험료·의료비·교육비·기부금 세액공제, 월세·연금계좌·혼인 세액공제, 세액감면, 납부특례세액
- 지방소득세, 중도 퇴사자 정산 방식, 종전 근무지 합산, 원천징수영수증 서식 출력
- 비과세 한도 초과분의 과세 전환(경고만 표시)

## 2. 적용 규칙 연도

- 계산 규칙은 **연도별로 분리**하고, 이번에는 2025년 귀속 규칙만 구현합니다.
- 귀속연도가 2025년이 아니면 2025년 규칙으로 계산하되 다음을 경고합니다.
  "○○년 귀속 급여에 2025년 귀속 규칙을 적용한 결과입니다. ○○년 개정 사항은 반영되지 않았습니다."
- 귀속연도 범위는 급여와 같은 2000~2100입니다.

## 3. 데이터 출처 (3차 연간 집계 재사용)

해당 귀속연도(`pay_year`)의 **확정된 급여 기간**만 사용합니다. 작성 중 급여는 제외하고 건수를 안내합니다.

| 계산 항목 | 급여 데이터 | 항목 코드 |
|---|---|---|
| 총급여 | 과세 지급 합계 (입력 당시 과세 구분 기준) | 지급 항목 중 `TAXABLE` |
| 연금보험료공제 | 국민연금 연간 합계 | `NATIONAL_PENSION` |
| 보험료 특별소득공제 | 건강보험 + 장기요양보험 + 고용보험 연간 합계 | `HEALTH_INSURANCE`, `LONG_TERM_CARE`, `EMPLOYMENT_INSURANCE` |
| 기납부세액 | 소득세 연간 합계 | `INCOME_TAX` |
| (경고용) 식대 | 월별 식대 금액 | `MEAL_ALLOWANCE` |

- 항목은 급여 입력 당시 복사해 둔 값(스냅샷)을 기준으로 합니다. 항목 코드는 `payroll_line.pay_item_id`로 연결된 `pay_item.code`를 사용합니다.
- 확정 급여가 없는 연도는 계산하지 않고 "확정된 급여가 없어 계산할 수 없습니다"를 안내합니다.

## 4. 입력 항목 (사원·귀속연도별 1건)

이름·주민등록번호·생년월일 등 개인 식별 정보는 **받지 않습니다.** 공제 요건(나이·소득·동거 등) 판단은 사용자가 하고, 시스템은 인원 수와 해당 여부만 받습니다.

| 항목 | 형식 | 규칙 |
|---|---|---|
| 배우자 기본공제 | 예/아니요 | |
| 부양가족 기본공제 인원 | 0~20명 | 본인·배우자 제외 |
| 경로우대(70세 이상) 인원 | 0명 이상 | 기본공제 대상자 수(본인 1 + 배우자 + 부양가족) 이하 |
| 장애인 인원 | 0명 이상 | 기본공제 대상자 수 이하 |
| 부녀자 공제 | 예/아니요 | 요건 판단은 사용자. 근로소득금액 3천만원 초과면 계산에서 적용하지 않고 안내 |
| 한부모 공제 | 예/아니요 | 배우자 기본공제와 함께 선택할 수 없음. 부녀자와 함께 선택하면 한부모만 적용 |
| 자녀세액공제 대상 자녀 수 | 0명 이상 | 부양가족 인원 이하. 안내: "기본공제 대상 자녀·손자녀 중 8세 이상 (2025년 귀속 국세청 안내 기준)" |
| 출산·입양 첫째 | 0~1명 | |
| 출산·입양 둘째 | 0~1명 | |
| 출산·입양 셋째 이상 | 0~10명 | 출산·입양 합계는 부양가족 인원 이하 |

- 입력 자료가 없으면 "본인 기본공제만 적용"으로 계산하고, 입력 자료가 없다는 것을 안내합니다.
- 논리 삭제된 사원은 입력·수정할 수 없고 조회만 가능합니다. 퇴사자는 입력할 수 있으나 중도 퇴사자 정산 방식은 반영하지 않는다고 안내합니다.

## 5. 계산 순서와 규칙 (2025년 귀속)

금액은 원 단위 정수(`long`)입니다. 비율 계산 결과의 **원 미만은 버립니다(가정, 5-9 참고).**

### 5-1. 총급여
총급여 = 확정 급여의 과세 지급 합계

### 5-2. 근로소득공제 → 근로소득금액
| 총급여 | 근로소득공제 |
|---|---|
| 500만원 이하 | 총급여 × 70% |
| 500만원 초과 1,500만원 이하 | 350만원 + (총급여 − 500만원) × 40% |
| 1,500만원 초과 4,500만원 이하 | 750만원 + (총급여 − 1,500만원) × 15% |
| 4,500만원 초과 1억원 이하 | 1,200만원 + (총급여 − 4,500만원) × 5% |
| 1억원 초과 | 1,475만원 + (총급여 − 1억원) × 2% |

- 공제액은 2천만원을 넘을 수 없고, 총급여보다 클 수 없습니다.
- 근로소득금액 = 총급여 − 근로소득공제 (이 프로젝트에서는 종합소득금액 = 근로소득금액)

### 5-3. 인적공제
- 기본공제 = (본인 1 + 배우자 여부 + 부양가족 인원) × 150만원
- 추가공제 = 경로우대 인원 × 100만원 + 장애인 인원 × 200만원 + (한부모 100만원 또는 부녀자 50만원)
  - 한부모와 부녀자를 모두 선택하면 한부모만 적용
  - 부녀자는 근로소득금액이 3천만원 이하일 때만 적용
- 인적공제 합계가 근로소득금액을 넘으면 넘는 금액은 없는 것으로 합니다.

### 5-4. 연금보험료공제·보험료 특별소득공제 → 차감소득금액
- 보험료 특별소득공제 = 건강보험 + 장기요양보험 + 고용보험 합계
- 연금보험료공제 = 국민연금 합계
- 차감소득금액 = 근로소득금액 − 인적공제 − 보험료 특별소득공제 − 연금보험료공제 (0원 미만이면 0원)
- 표시할 적용액: 인적공제 → 보험료 특별소득공제 → 연금보험료공제 순으로 남은 금액 안에서 적용하고, 남은 금액을 넘는 부분은 "한도 초과로 미적용"으로 표시합니다. (연금보험료공제를 마지막에 줄이는 것은 제51조의3③ 해석이며, 과세표준에는 영향이 없습니다.)

### 5-5. 과세표준 → 산출세액
과세표준 = 차감소득금액 (그 밖의 소득공제는 범위 밖)

| 과세표준 | 산출세액 |
|---|---|
| 1,400만원 이하 | 과세표준 × 6% |
| 1,400만원 초과 5,000만원 이하 | 84만원 + (과세표준 − 1,400만원) × 15% |
| 5,000만원 초과 8,800만원 이하 | 624만원 + (과세표준 − 5,000만원) × 24% |
| 8,800만원 초과 1억5천만원 이하 | 1,536만원 + (과세표준 − 8,800만원) × 35% |
| 1억5천만원 초과 3억원 이하 | 3,706만원 + (과세표준 − 1억5천만원) × 38% |
| 3억원 초과 5억원 이하 | 9,406만원 + (과세표준 − 3억원) × 40% |
| 5억원 초과 10억원 이하 | 1억7,406만원 + (과세표준 − 5억원) × 42% |
| 10억원 초과 | 3억8,406만원 + (과세표준 − 10억원) × 45% |

### 5-6. 세액공제
- **근로소득세액공제** = min(공제액, 한도)
  - 공제액: 산출세액 130만원 이하 → 산출세액 × 55% / 초과 → 71만5천원 + (산출세액 − 130만원) × 30%
  - 한도(총급여 기준): 3,300만원 이하 74만원 / 7천만원 이하 max(66만원, 74만원 − (총급여 − 3,300만원) × 8/1000) / 1억2천만원 이하 max(50만원, 66만원 − (총급여 − 7천만원) × 1/2) / 초과 max(20만원, 50만원 − (총급여 − 1억2천만원) × 1/2)
- **자녀세액공제** = 자녀 수 공제 + 출산·입양 공제
  - 자녀 수: 1명 25만원 / 2명 55만원 / 3명 이상 55만원 + (자녀 수 − 2) × 40만원
  - 출산·입양: 첫째 × 30만원 + 둘째 × 50만원 + 셋째 이상 × 70만원
- **표준세액공제** = 보험료 특별소득공제액이 0원이면 13만원, 아니면 0원 (결정 3)

### 5-7. 결정세액
결정세액 = 산출세액 − 세액공제 합계 (0원 미만이면 0원, **가정** 5-9)

### 5-8. 추가 납부 / 환급
차감액 = 결정세액 − 기납부세액
- 0원 초과: 추가 납부 / 0원 미만: 환급(절댓값) / 0원: 차이 없음

### 5-9. 가정 (조사로 확인하지 못한 것, 화면·문서에 "가정"으로 표시)
1. 각 단계 비율 계산의 원 미만은 버린다.
2. 세액공제 합계가 산출세액을 넘으면 결정세액은 0원으로 한다.
3. 보험료 공제 적용액을 표시할 때의 순서(5-4)는 계산 결과(과세표준)에 영향을 주지 않는다.

## 6. 경고·안내 문구

| 조건 | 문구 |
|---|---|
| 항상 | 모의 계산 · 전문가 검증 전 · 지방소득세 미포함 |
| 귀속연도 ≠ 2025 | ○○년 귀속 급여에 2025년 귀속 규칙을 적용한 결과입니다. ○○년 개정 사항은 반영되지 않았습니다. |
| 식대가 월 20만원을 넘는 달이 있음 | 식대가 월 20만원을 넘는 달이 있습니다(○월). 비과세 한도 초과분의 과세 전환은 반영하지 않았습니다. |
| 작성 중 급여가 있음 | 작성 중인 급여 N건은 계산에서 제외했습니다. |
| 입력 자료 없음 | 연말정산 입력 자료가 없어 본인 기본공제만 적용했습니다. |
| 부녀자 선택 + 근로소득금액 3천만원 초과 | 근로소득금액이 3천만원을 넘어 부녀자 공제를 적용하지 않았습니다. |
| 부녀자·한부모 모두 선택 | 한부모 공제만 적용했습니다. |
| 한도 초과로 미적용된 공제 | ○○ 공제 중 N원은 한도 초과로 적용되지 않았습니다. |
| 퇴사자 | 중도 퇴사자 정산 방식은 반영하지 않았습니다. |
| 확정 급여 없음 | 확정된 급여가 없어 계산할 수 없습니다. |

## 7. 데이터 설계안 (V3 마이그레이션, 4-3에서 SQL 작성·승인)

테이블 `year_end_input` — 연말정산 입력 자료. **계산 결과는 저장하지 않고** 조회할 때마다 계산합니다.

| 컬럼 | 타입 | 제약 |
|---|---|---|
| id | BIGINT | PK, AUTO_INCREMENT |
| employee_id | BIGINT | NOT NULL, FK → employee(id) |
| tax_year | INT | NOT NULL, 2000~2100 |
| spouse_deduction | BOOLEAN | NOT NULL |
| dependent_count | INT | NOT NULL, 0~20 |
| elderly_count | INT | NOT NULL, 0 이상 |
| disabled_count | INT | NOT NULL, 0 이상 |
| woman_deduction | BOOLEAN | NOT NULL |
| single_parent_deduction | BOOLEAN | NOT NULL, 배우자 기본공제와 동시 불가 |
| child_credit_count | INT | NOT NULL, 0 이상, dependent_count 이하 |
| birth_first_count | INT | NOT NULL, 0~1 |
| birth_second_count | INT | NOT NULL, 0~1 |
| birth_third_plus_count | INT | NOT NULL, 0~10 |
| created_at, updated_at | DATETIME(6) | NOT NULL |

- UNIQUE(employee_id, tax_year)
- 인원 수 상한처럼 여러 컬럼에 걸친 규칙(경로우대·장애인 ≤ 기본공제 대상자 수, 출산·입양 합계 ≤ 부양가족)은 가능한 범위에서 CHECK로, 나머지는 엔티티 검증으로 처리합니다.
- 기존 V1·V2와 기존 테이블은 변경하지 않습니다.

## 8. API·화면 (4-3·4-4에서 확정)

API 명세: [api/year-end-api.md](api/year-end-api.md)

| API | 설명 |
|---|---|
| `GET /api/year-end/{year}/employees` | 그 해 확정 급여가 있는 사원 목록 + 입력 여부 + 결과 요약 |
| `GET /api/year-end/{year}/employees/{id}/input` | 입력 자료 조회 (없으면 기본값) |
| `PUT /api/year-end/{year}/employees/{id}/input` | 입력 자료 저장 |
| `GET /api/year-end/{year}/employees/{id}/result` | 계산 결과 (단계별 금액, 적용 규칙, 경고) |

| 화면 경로 | 설명 |
|---|---|
| `/year-end?year=` | 연말정산 목록 (연도 선택, 요약 카드, 사원별 모의 계산 표) |
| `/year-end/employees/:employeeId?year=` | 계산 결과 (경고, 7단계 계산표, 계산에 쓴 급여 합계, 가정) |
| `/year-end/employees/:employeeId/input?year=` | 입력 자료 (인원 수·해당 여부, 논리 삭제된 사원은 읽기 전용) |

- 사이드바의 "연말정산" 메뉴를 활성화했습니다("준비 중" 표시 제거).
- 인원 입력은 커스텀 드롭다운(WAI-ARIA combobox)입니다. 아래로 열리면 위에서부터 0 → 최대값, 위로 열리면 선택창 바로 위가 0이고 멀어질수록 커지며, 방향키는 화면에 보이는 방향으로 움직입니다.

## 9. 테스트 기준 (4-2 계산 로직)

- **국세청 공식 사례**
  - 총급여 3,380만원 → 근로소득공제 10,320,000원, 근로소득금액 23,480,000원
  - 과세표준 2,000만원 → 산출세액 1,740,000원
- **구간 경계값**: 근로소득공제 5구간(500만·1,500만·4,500만·1억원 전후, 2천만원 한도), 기본세율 8구간 경계, 근로소득세액공제 공제액 130만원 경계와 한도 4구간(최소값 포함)
- **한도·조건**: 인적공제 > 근로소득금액, 차감소득금액 0원, 부녀자 3천만원 조건, 한부모·부녀자 동시 선택, 세액공제 > 산출세액(결정세액 0원), 표준세액공제(보험료 0원일 때만), 자녀 0·1·2·3·5명, 출산·입양 조합
- **입력 검증**: 인원 수 범위, 배우자·한부모 동시 선택 거부, 자녀 수 > 부양가족 거부
- 계산 로직은 DB 없이 실행되는 순수 Java 클래스로 만들고 단위 테스트로 검증합니다.
